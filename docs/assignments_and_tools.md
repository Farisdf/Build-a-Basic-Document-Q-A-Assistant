# CS 201 — Programming Assignments and Tooling

## Assignment schedule

There are four programming assignments in CS 201. Assignment 1 (linked lists and stacks) is
released in Week 2 and due on Friday 26 September 2025. Assignment 2 (hash tables) is released
in Week 5 and due on Friday 17 October 2025. Assignment 3 (binary search trees and heaps) is
released in Week 8 and due on Friday 7 November 2025. Assignment 4 (graph algorithms) is
released in Week 11 and due on Friday 28 November 2025. All assignments are due at 11:59 pm.

## Submission method

Assignments are submitted through the course GitLab server at gitlab.example-university.edu.
Each student has a private repository named cs201-<username>. The submission for each
assignment must be on the main branch inside a folder called assignment1, assignment2,
and so on. The last commit pushed before the deadline is the one that is marked. Email
submissions are not accepted.

## Language, version, and allowed libraries

All assignments must be written in Python 3.12. Only the Python standard library may be used;
third-party packages such as NumPy or pandas are not allowed, and a submission that imports
them will fail the automated tests and receive zero for the automated portion. Type hints
are encouraged but not required.

## Automated tests and marking

Each assignment is marked out of 100. 70 marks come from automated tests that are run against
the submission after the deadline, and 30 marks come from a code-quality review by a TA
covering readability, naming, comments, and appropriate use of data structures. A public
subset of the automated tests is provided with each assignment so students can check their
work before submitting. Marks and feedback are released on the course website within
10 working days of the deadline.

## Regrade requests

A student who believes an assignment has been marked incorrectly can submit a regrade request
through the course website within 7 days of marks being released. The request must explain
specifically which test or rubric item is disputed. Regrades are carried out by a different
TA from the original marker, and the mark can go up or down.

## Getting help

The primary place to ask questions is the course discussion forum on the course website.
Students should not post assignment code on the forum. For questions that require sharing
code, students should attend TA office hours, which are held on Mondays from 3:00 pm to
5:00 pm in Room 118 of the Turing Building, or book a private appointment with the instructor.
